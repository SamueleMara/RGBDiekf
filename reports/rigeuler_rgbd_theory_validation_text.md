## 2. Adaptations that go beyond the reference, with their justification

1. **Continuous rasterizer.** A point renderer with a z-buffer front is discontinuous in the positions; 3DGS alpha compositing is not.
   * Under a hard band, a pixel's prediction jumps when a sample crosses the band, or when an edge sample (w → 0) leaves the pixel and the front moves to another surface.
   * The trust-region gain ratio assumes the model agrees with the objective as the step shrinks. On a jump it rejects every step and the radius goes to its floor. This was measured: the moving plate stalled half-way.
   * The fix makes each sample's power to occlude fade with its footprint weight: `ζ = z + b(1/w − 1)`, followed by a C¹ visibility taper. The render is then continuous, and its Jacobian is exact for the frozen front contributor.
2. **Coverage-tempered Student-t.** Gating RGB and depth at A ≥ 0.05 on both channels is a discontinuity of the same kind.
   * The reference gates depth only; its RGB is alpha-composited and continuous.
   * `A·ρ(z)` is the tempered likelihood `t(y; h, σ)^A`. It is zero exactly where no prediction exists, so nothing is synthesized there.
3. **Covariance carried between frames.** Two restricted-Joseph methods are implemented:
   * the exact structured recursion `e = d + Gξ`, which equals the dense 6N Joseph recursion to ≤ 2·10⁻¹⁰ over 5 frames on growing fixtures;
   * the assumed-density marginals, exact for one frame and 19–39% low after 5 frames.

   Both diverge on the blade (§4). The complete runs therefore carry RigEuler's block information, which on the fixtures is 20–1000× below the exact covariance. It is the only bounded method, and it is reported as an approximation, not as a calibrated covariance.
4. **Joseph posteriors in Phase 2/3.** With Student-t IRLS weights, W ≠ R⁻¹. The reference information inverse is therefore not the error covariance; `A⁻¹(N + JᵀWRWJ)A⁻¹` is. The trace ratio between the two is reported per frame.
5. **Information-supported coherence.** The derivation is in `supported_coherence.py`. With full support it is bitwise the pinned extractor. In the occlusion simulations (below), it fixes the case the pinned extractor gets wrong: a hidden half reversing direction, IoU 0.5 → 1.0.
6. **Persistence null for the joint decision.** On the static control, a noise-selected core displaced by a constant pose out-predicts the bare static scene by about 145 nats/frame (p ≈ 1e-28) without any motion. It is absorbing the catalogue's model error.
   * The null for "systematic motion" is therefore persistence: the core at its previous Phase-2 pose. That null absorbs any constant displacement but lags real motion, and it is just as causal.
   * The static-scene comparisons are still reported, as diagnostics.
7. **Predictive joint decision.** One loss per frame, so pixel dependence is never ignored. The geometry is fitted causally on Phase-2 poses before frame k. The long-run variance is `max(Newey–West, AR(1))`, because Newey–West alone was measured to reject a true null 13–21% of the time at nominal 5% (n = 56, AR(1) 0.5–0.7). This choice was made on simulated null series only.

## 3. Properties of the pinned reference that the gates expose (reproduced, not introduced)

* **IRLS curvature in the robust regime.** Along the exact Gauss–Newton direction of a Phase-1 frame (the small fixture), the true objective is nearly linear up to 3× the GN step. The measured actual decrease is 932 / 1715 / 2269 at α = 1 / 2 / 3, against a model prediction of 627 / 0 / −1881. The IRLS curvature (which the reference also uses) therefore overestimates the true curvature 3–4× when many residuals sit in the Student-t tail.
  * The reference trust region accepts these interior steps with ρ ≈ 2, but enlarges the radius only at the boundary.
  * Within its 10-iteration budget, a frame with large inter-frame motion therefore converges only partially.
  * This is the reference step control, ported unchanged; it is reported rather than retuned.

* The pinned coherence selection resolves a "moving" component on a static noise-only scene. Under a pure global drift it recruits every node.
* Static scenes must therefore be rejected downstream, by the predictive joint comparison against the static scene (`NO_IDENTIFIABLE_JOINT`).

## 4. Failure: restricted-Joseph covariance diverges at blade scale (earliest failing gate)

Both runs are preserved for inspection.

**Exact structured recursion.** Run `image_iekf_v2_failed_exact_covariance_frame11_20261024`.
* The median posterior position variance grows from 3.7e-4 to 3.8e-2 m² over frames 1–10.
* The intra-group part `D` matches `t² σ_v²` for the independent initial velocity prior σ_v = 1 m/s (1.19e-3 against 1.15e-3 at frame 2).
* The extremes reach 1e5 m² and 3e6 m²/s².
* A posterior block was indefinite at frame 10. At frame 11 the run raised `LinAlgError` (`B` not positive definite).

**Assumed-density restricted-Joseph marginals.** Run `image_iekf_v2_failed_assumed_density_divergence_20261024`.
* The maximum position variance went 1.3e-2 → 2.1e-1 → 5.8 → 6.5e2 → 1.5e4 m² over frames 1–5, and reached 1e18 at frame 14.
* The median reached 4.8e7 m² by frame 19. There were 20,649 PSD repairs at frame 19, and the Cholesky failed at frame 20.

**Mechanism.** The restricted gain `K_G = G B⁻¹GᵀHᵀW` corrects only the 12 coordinates of each computational group.
* Each point's deviation from its group's rigid motion is measured by the images, but it cannot be corrected individually.
* Under the Phase-1 prior (independent point velocities, σ_v = 1 m/s), that deviation enters the group correction (the `U P⁻ Uᵀ` term of the Joseph form) as unmodelled error.
* That error inflates every member's covariance, which then feeds the next frame's group correction.
* The error covariance of the implemented estimator is therefore unstable under its own model. The 5-frame fixtures were too short and too small to show it.

**Consequences.**
* `FILTER_NUMERICALLY_VALID` holds for every recursion, Jacobian and dense covariance gate. It does NOT hold for a calibrated Phase-1 covariance at blade scale.
* The complete runs carry the bounded reference block information, an optimistic approximation. Its per-point uncertainties are not calibrated.
* The estimator's tracking does not depend on this (see the GT evaluation). Only the reported uncertainty and the solver's prior weighting do.

**What would resolve it**, outside this contract: a Phase-1 prior that couples points within a group (consistent with the restriction), or an unrestricted per-point correction.
